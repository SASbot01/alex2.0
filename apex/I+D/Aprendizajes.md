# Aprendizajes — Apex

Bitácora de lo que se probó y **no funcionó** (o funcionó pero no se promovió). El valor no está en la idea — está en saber por qué se descartó para no repetir el ciclo en 6 meses.

Formato:

```
## YYYY-MM-DD — <título corto>

**Hipótesis:** ...
**Cómo se probó:** ...
**Resultado:** ...
**Por qué no se promovió:** ...
**Reabrir si:** <condición que cambiaría la decisión>
```
